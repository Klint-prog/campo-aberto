# Código de conduta

O Campo Aberto Tecnologia Rural busca ser uma comunidade técnica aberta, respeitosa e colaborativa.

## Comportamentos esperados

- Tratar pessoas com respeito.
- Discutir ideias, código e decisões técnicas sem ataques pessoais.
- Receber feedback com abertura.
- Explicar decisões técnicas com clareza.
- Respeitar diferenças regionais, culturais, profissionais e de experiência.
- Priorizar colaboração, segurança e qualidade do projeto.

## Comportamentos inaceitáveis

- Assédio, intimidação ou discriminação.
- Ofensas pessoais.
- Exposição de dados privados.
- Publicação de segredos, credenciais ou informações sensíveis.
- Spam, autopromoção abusiva ou desvio deliberado de discussões.
- Pressão para implementar fases futuras fora do escopo aprovado.

## Aplicação

Mantenedores podem editar, ocultar ou remover comentários, issues, pull requests ou contribuições que violem este código de conduta.

Violações graves podem resultar em bloqueio de participação no projeto.

## Escopo

Este código se aplica a issues, pull requests, discussões, documentação, exemplos, canais de comunidade e interações relacionadas ao Campo Aberto.
